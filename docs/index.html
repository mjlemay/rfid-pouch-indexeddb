The Simple RFID Notekeeper

Scan a tag, keep a note. Everything stays in your browser.

Plug in a USB RFID reader, scan a tag, and the app opens a record for it. Add notes and templated fields such as owner, quantity, or in service. Every record, scan, and change is stored in the browser with IndexedDB. Nothing leaves the machine, and the records can be exported and imported as JSON or CSV.

How to run it

  1. Download the zip.
  2. Unzip it. You get a folder named simple-rfid-notekeeper.
  3. Open index.html inside that folder in Chrome or Edge.
  4. Plug in the USB RFID reader and scan a tag.
  5. Keep using the same browser on the same machine. The data lives in that browser, and clearing its site data deletes it.
  6. Use Import and Export inside the app to move records to another browser or machine.
